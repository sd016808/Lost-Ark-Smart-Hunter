2任務啟動與停止 (時序)

100% 
sequenceDiagram
    actor U as 使用者
    participant HK as HotkeyListener (主執行緒)
    participant BC as BotController
    participant CTX as BotContext
    participant TR as TaskRunner
    participant T as 任務執行緒
    participant CC as 戰鬥執行緒

    U->>HK: Ctrl+F10
    HK->>BC: ToggleDailyChaos()
    BC->>BC: 樂園 / 地獄正在跑？是 → 嗶兩聲不動作 (BlockedBy)
    BC->>CTX: AttachGame()
    CTX->>CTX: FindByProcess("LOSTARK") + ClientSize
    alt 找不到視窗
        CTX-->>BC: false → 提示、不開始
    else 第一次 / 視窗換了 / 大小變了
        CTX->>CTX: 重建 UiLayout / UiTemplates / Finish / Portal / Input
    end
    BC->>TR: Start(DailyChaosTask)
    TR->>TR: Stop() 上一個 (最多等 5 秒)
    TR->>T: new Thread(Run)
    loop 任務中
        T->>T: Wait.For / UiActions (都看 ct 與 BotClock)
        T-->>CC: BotStatus.ReplayActive / ArenaFighting = true
        CC->>CC: CanCast 成立就循環放技能
    end
    U->>HK: F10
    HK->>BC: TogglePause → BotClock.Pause()
    Note over T,CC: Wait.For 停在原地；Gamepad 一律送 0；CanCast = false
    U->>HK: Ctrl+F10
    HK->>BC: StopTask → Gamepad.ReleaseAll, TR.Stop()
    TR->>T: cts.Cancel() + BotClock.Resume()
    alt 5 秒內停下來
        TR-->>BC: true → 「已手動停止」
    else 卡在 OCR 等不能中途取消的動作
        TR-->>BC: false → 任務維持「執行中」，不能開新任務
    end

3每日混沌副本：一隻角色的流程 (時序)

100% 
sequenceDiagram
    participant DC as DailyChaosTask
    participant CS as CharacterSwitcher
    participant GF as GuildFlow
    participant DE as DungeonEntry
    participant RT as ReplayRouteTask
    participant RP as DailyRunReport

    DC->>CS: SwitchTo(slot)
    CS->>CS: 列表沒開 → ESC → 「立即使用其他角色登入」<br/>讀「登入中」是第幾隻 (LastRunCheck.Verify 上一隻次數有沒有扣)
    CS->>CS: 捲到 slot、點角色格、等面板名字變<br/>PaddleOCR 讀「混沌副本 A/B」
    alt A 小於 100
        CS-->>DC: loggedIn = false (列表不關，直接看下一隻)
        DC->>RP: row.Skip
    else A 大於等於 100
        CS->>CS: 登入 → 確認 → WaitForLoading
        CS-->>DC: loggedIn = true
        DC->>GF: Run (簽到一定做；guildDonate 才捐銀幣)
        GF-->>DC: GuildResult (失敗只跳過，不影響副本)
        DC->>DE: Enter(wanted 或 null = 自動)
        DE->>DE: Alt+Q 戰況板 → 節點 → 庫爾湛視窗 → 領每週獎勵<br/>→ 左側列表 (OCR 確認) → 無法入場？換下一個 → 入場 → 接受
        DE-->>DC: 進了哪個副本 (或 null = 只做公會)
        DC->>RT: Run (Quiet) 直到結算 / 倒數 00:00 / 逾時
        RT-->>DC: ReplayOutcome (通關、時間、死亡、片鱗)
        DC->>RP: RecordRun → stats/yyyy-MM.jsonl
        DC->>CS: lastRun.RunFinished (下次開列表時確認次數已扣)
    end
    DC->>RP: Finish → 主控台結算表 + reports/*.html

4重播主迴圈 (ReplayRouteTask.Run 每一幀)

100% 
flowchart TD
    S([每幀 33ms]) --> F{每 15 幀<br/>結算畫面？}
    F -->|是| DONE([通關，結束])
    F -->|否| D{每 30 幀<br/>死亡視窗？}
    D -->|是| REV[Revive：等「立即復活」可按 → 點<br/>10 秒不能按改「據點復活」→ 從最近點重走]
    D -->|否| TM{每 2 秒<br/>倒數 00:00<br/>連續 5 次？}
    TM -->|是| TO([時間到，結束])
    TM -->|否| MM[截小地圖 → MinimapLocalizer.Update<br/>local 搜尋 → 失敗才 global]
    MM --> SH[每 3 幀小地圖找片鱗<br/>每 6 幀畫面找片鱗名牌 → ShardTracker]
    SH --> NAV[RouteNavigator.Tick]
    NAV --> LS{目標是互動點 而且<br/>直衝中 或 20px 內<br/>頭上有 LS？}
    LS -->|是| RI
    LS -->|否| PR{每 5 幀：<br/>直衝中？}
    PR -->|否| CPR[CheckPortalRush<br/>見第 5 張]
    PR -->|是| WATCH[重新找傳送門畫疊加層<br/>1.5 秒看不到 → AbortRush]
    NAV -->|Finished| TAIL[路線走完：在最後 10 點來回打<br/>最多 5 分鐘]
    NAV -->|ReachedInteract| RI[RunInteraction<br/>按 LS → 位置移動 35px = 過圖<br/>沒過圖 → HomeToPortal 靠近再按，最多 5 次]
    RI -->|過圖| ADV[AdvanceAfterInteract<br/>ForceGlobal 重新定位]
    RI -->|沒過圖| RETRY[回前 15 點繞一圈清怪再試<br/>最多 5 分鐘後跳過]

5看到傳送門直衝互動點 (狀態)

100% 
stateDiagram-v2
    [*] --> 照路線走
    照路線走 --> 靠近互動點: 小地圖座標到下一個互動點 ≤ 60 地圖 px
    靠近互動點 --> 照路線走: 畫面上有怪的血條 (怪沒清完)
    靠近互動點 --> 靠近互動點: 形狀 / 特徵圖認傳送門；方向要對、畫面距離 ÷ 地圖距離要在 15~60
    靠近互動點 --> 直衝: 形狀認出或分數 ≥ 0.85 一次就去；0.75~0.85 累積 2 次 (3 秒內)
    直衝 --> 到互動點: 頭上出現 LS，或小地圖到了
    直衝 --> 取消直衝: 連續 1.5 秒看不到傳送門也沒 LS
    直衝 --> 取消直衝: 20 秒走不到
    到互動點 --> 過圖: 按 LS 後位置移動超過 35px
    到互動點 --> 取消直衝: 畫面上沒傳送門也沒 LS，或按了沒過圖
    取消直衝 --> 照路線走: CancelRush：回直衝前的進度，從最近的點接回；同一互動點誤判 2 次就不再直衝
    過圖 --> 照路線走: 等畫面穩定 → 全域重新定位

6地獄：一層與一場 (狀態)

100% 
stateDiagram-v2
    [*] --> 進場: 戰況板 → 樂園 → 地獄分頁 → 鑰匙 (綠、白、橘、紫、藍的順序，奈落不用) → 入場
    進場 --> 讀面板
    state 讀面板 {
        [*] --> 樓層_可下墜_按鈕列
    }
    讀面板 --> 等按鈕變灰: 剛落地按鈕還是上一層的亮
    等按鈕變灰 --> 打怪: 變灰 (有怪)
    等按鈕變灰 --> 清完: 8 秒都亮 (這層沒怪)
    讀面板 --> 祭壇: 11 的倍數 / 50 層，先找祭壇 (100 層打完王才找)
    打怪 --> 打怪: 原地 15 秒 → 繞場 (上右下左)；看到血條就追 (最多 20 秒，再冷卻 10 秒)
    打怪 --> 祭壇: 每秒看一次，看到紅球就先用
    打怪 --> 清完: 按鈕連續 3 次亮
    打怪 --> 整場打完: 「再次挑戰」灰「離開」亮
    祭壇 --> 清完: 走到 LS → 互動 → 跳視窗就放藍鑰匙淬鍊，沒跳 = 直接領獎
    清完 --> 找互動點: 停技能
    找互動點 --> 找互動點: 往上 → 上面挑 (綠優先) → 往左 → 往右；整數樓層前 2 輪只認綠
    找互動點 --> 打怪: 按鈕又變灰 (又有怪)
    找互動點 --> 走過去: 看到箭頭 (一路追同一個)
    走過去 --> 按互動: 90px 內、或頭上 LS / 「下降」
    按互動 --> 讀面板: 樓層變了 (等 2.5 秒落地)
    按互動 --> 找互動點: 15 秒沒變，最多 4 次
    整場打完 --> 開寶箱: 先看一遍 (上/左/右) 再照 chestPriority 挑；「再次挑戰」亮了才算開了
    開寶箱 --> 進場: 等 8 秒 → 再次挑戰 → 選鑰匙
    開寶箱 --> [*]: 沒有鑰匙 → 離開 → 換下一隻角色

7樂園 (天堂)：一隻角色 (狀態)

100% 
stateDiagram-v2
    [*] --> 角色列表: ESC → 讀右側面板「樂園 A/B」
    角色列表 --> [*]: A = 0 不登入 (列表不關看下一隻)
    角色列表 --> 樂園視窗: 登入 → 戰況板 → 樂園
    樂園視窗 --> 樂園視窗: 點「天堂」分頁到變金色 → 選最高階段
    樂園視窗 --> [*]: 入場灰 (次數讀到大於 0 時還是按按看，沒跳確認視窗才算沒次數)
    樂園視窗 --> 副本中: 入場 → 接受 → 讀取
    副本中 --> 往上走: 剛進場往正上方走 3 秒 (王在北邊)
    往上走 --> 打怪
    打怪 --> 打怪: 每 0.2 秒找血條，看到約每秒推一下；有王圖示時目標在血條下方 330px；3 秒沒血條輪流上左下右挪；遊戲自動重複下一場
    打怪 --> 打完: 「離開」亮 + 「再次挑戰」灰，連續 2 次；(或 OCR 次數 0/5；或「離開」持續 15 秒)
    打完 --> [*]: 等 2 秒撿東西 → 離開 → 確認 → 讀取 → 下一隻

8畫面辨識的資料流

100% 
flowchart LR
    GW[GameWindow.Capture<br/>client 座標的一塊 BGR Mat] --> UL
    UL[UiLayout<br/>2560x1440 基準座標 × 視窗比例] --> UT["UiTemplates.Find<br/>特徵圖 ±25% 多尺度比對<br/>記住上次成功倍率"] --> AN[UiMatch 錨點<br/>Center / Score / Scale]
    AN -->|FromAnchor 推算| BTN[按鈕 / 文字區塊的位置]
    BTN --> OCR{讀字}
    OCR -->|名字 / 次數 / 副本名 / 樓層| PO[PaddleOcr<br/>PP-OCRv5，OpenCV DNN，編進 exe]
    OCR -->|血量 / 倒數 / 捐贈「銀」| WO[TextOcr<br/>Windows OCR，3 秒逾時]
    BTN --> COL[顏色 / 亮度判斷<br/>按鈕金色 vs 灰、白字比例、紅色的 0]
    GW -->|整張| REF[HellScreen.ToReference<br/>縮成 2560 寬] --> SHAPE[顏色遮罩 → 連通區塊 → 形狀規則<br/>地獄箭頭 / 傳送門 / 血條 / 紅球 / 寶箱名牌]
    GW -->|小地圖| MM[縮成 392x348 → 抽地板前景<br/>MinimapLocalizer 在 3072² 畫布上定位]
    PO & WO & COL & SHAPE & MM --> DEC[任務的判斷]
    DEC --> IN[InputSimulator<br/>滑鼠鍵盤：選單]
    DEC --> GP[Gamepad<br/>虛擬搖桿：走路、技能、LS 互動]
    DEC --> OVL[Overlay<br/>畫在遊戲上，截圖看不到]
