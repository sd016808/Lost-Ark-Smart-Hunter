# Smart Hunter Engine

Lost Ark (失落的方舟) 自動化工具：自動重播錄好的副本路線、自動施放技能，並能一鍵跑完所有角色的**每日混沌副本**（切換角色、公會簽到 / 捐贈、領每週獎勵、進副本、打完換下一隻）。

作者：吃泡麵度年的SD

---

## 下載與安裝

1. 到 [Releases](https://github.com/sd016808/Lost-Ark-Smart-Hunter/releases/latest) 下載最新版的 `SmartHunter_vX.X.X.zip`。
2. **整個 zip 解壓縮到同一個資料夾**：`LostArkSmartHunter.exe`、所有 `.dll`、`Routes` 資料夾要放在一起，只拷 exe 無法執行。
3. 安裝虛擬搖桿驅動 **ViGEmBus**：到 [ViGEmBus Releases](https://github.com/nefarius/ViGEmBus/releases) 下載安裝檔安裝（只需要裝一次）。剛開機時驅動可能還沒準備好，程式會自動重試連線。
4. **對 `LostArkSmartHunter.exe` 按右鍵 →「以系統管理員身分執行」**。遊戲不接受一般權限程式送出的按鍵與滑鼠操作，不用系統管理員身分執行會沒有反應。

> 不需要另外安裝 .NET。

## 使用前請確認

- 遊戲解析度必須是 **16:9 且至少 1920x1080**（例如 1920x1080、2560x1440、3840x2160）。16:10 等其他比例目前不支援。
- 遊戲視窗**不能被其他視窗擋住，也不能最小化**（程式靠截取遊戲畫面辨識）。
- 執行中**不要調整遊戲視窗大小**。

## 快捷鍵

| 按鍵 | 功能 |
|---|---|
| **Ctrl+F10** | 開始 / 停止**每日混沌副本**（依 `settings.json` 設定的角色依序處理） |
| **Ctrl+F8** | 開始 / 停止**樂園 (天堂)**（跟每日混沌副本用同一份角色設定） |
| **Ctrl+F5** | 開始 / 停止**地獄**（跟每日混沌副本用同一份角色設定，每個角色都會登入） |
| **F10** | 在副本裡按：自動辨識副本並重播路線（每日任務、樂園、地獄進行中則為暫停 / 繼續） |
| **F6** | 開關自動施放技能 |
| F9 | 開始 / 停止錄製路線 |
| F7 | 錄製時標記互動 / 過圖點 |
| F11 | 儲存錄製的路線 |
| Ctrl+F11 | 產生所有路線的預覽圖 |

## 每日混沌副本設定 (settings.json)

第一次執行時會在 exe 旁邊自動產生 `settings.json`，用記事本打開修改即可（每次開始任務時重新讀取，改完不用重開程式）。資料夾裡的 `settings.example.json` 是範例（每次更新會換成最新版，可以對照看有沒有新的設定），不用改它。

```jsonc
{
  "replay": { "pauseEveryPx": 40, "pauseMs": 2000, "extraWaitMs": 500 },
  "daily": {
    "guildDonate": true,        // 公會簽到後是否順便捐贈銀幣
    "exitGameWhenDone": false   // 全部角色處理完後是否自動關閉遊戲
  },
  "characters": [
    { "slot": 1, "dungeon": "涅夫塔1作戰" },   // 指定要打的副本
    { "slot": 2 }                              // 不填 dungeon = 自動選能打的最高副本
  ],
  "characterNames": [ "角色名字1", "角色名字2" ]   // 選填：統計報表的角色名字白名單
}
```

- **slot**：角色在「立即使用其他角色登入」列表中的位置，由左到右、由上到下為 1、2、3…，最多 30 隻（超過 9 隻會自動捲動列表）。多個帳號可以共用同一份設定：slot 照角色最多的帳號設就好，角色比較少的帳號沒有的 slot 會自動略過，也不會出現在結算表。
- **dungeon**：可填 `亞比都斯1作戰`、`亞比都斯2作戰`、`亞比都斯3作戰`、`涅夫塔1作戰`。
  **不填**（或填 `"自動"`）會依序檢查 涅夫塔1 → 亞比都斯3 → 亞比都斯2 → 亞比都斯1，打第一個能入場的；都不能打就只做公會簽到。
- 不想處理的角色，把那一行刪掉即可。混沌副本次數 >= 100 的角色才會進副本。
- **characterNames**（選填）：所有角色的名字。填了之後，統計報表讀到的角色名字會換成清單裡最接近的一個（修正辨識錯的字，例如名字最後的 o 讀成 0）；跟清單裡每個名字都差太多（例如新角色忘了加）就照辨識到的記。以前已經記錄的名字也會照白名單修正後再統計 (紀錄檔本身不改)。
- 設定有錯時，開始任務會直接顯示哪一行有問題。

### 每日任務會做的事
1. 依 slot 順序切換到每個角色；混沌副本次數不夠打 (少於 100) 的角色不登入，直接跳過 (也不做公會簽到)。
2. 公會簽到（`guildDonate` 為 true 時再捐贈銀幣）。
3. 混沌副本次數足夠就：領每週淨化任務獎勵 → 進副本 → 照錄好的路線打完。
4. 全部完成後發出提示音；若 `exitGameWhenDone` 為 true 則自動關閉遊戲。

中途停止後重按 Ctrl+F10 從頭跑：已經打過副本的角色次數已扣掉，會直接跳過不登入。

### 樂園 (天堂) (Ctrl+F8)
1. 依 `characters` 的 slot 順序切換到每個角色；角色列表右側「樂園(天堂)」次數是 0 的角色不登入，直接跳過（`dungeon` 欄位不影響樂園）。
2. 戰況板 → 樂園 → 切到「天堂」分頁 → 選能打的最高階段 → 入場。
3. 剛進場先往上（王座的方向）走 3 秒，之後一直施放技能（跟混沌副本一樣用 F6 的自動技能，搖桿會自動瞄準王）；遊戲會自動重複打完全部次數。
4. 次數變成 0、左上出現「離開」→ 離開副本，換下一個角色。只打樂園，不做公會簽到和混沌副本。

打到一半可以按 F10 暫停、手動操作，再按 F10 繼續。樂園和每日混沌副本不能同時跑：一個在跑時按另一個的快捷鍵不會動作，請先按原本的快捷鍵停止。

### 地獄 (Ctrl+F5)
1. 按 **Ctrl+F5**：依 `characters` 的 slot 順序登入每個角色（角色列表看不到地獄次數，所以每隻都會登入），打開戰況板 →「樂園」→「地獄」分頁，選鑰匙入場（綠色 > 橘色 > 紫色 > 藍色，**奈落鑰匙不用**），沒有可用的鑰匙就換下一隻。
2. 每一層：自動施放技能打怪，原地打一陣子還沒清完會在場地裡繞一繞找怪；左上「中斷並獲得獎勵」變亮代表這層清完，停止施放技能。
3. 畫面上有祭壇（紅色圓球）就走過去使用：要放鑰匙的祭壇只放**藍色**地獄鑰匙，沒有就不放。
4. 走到往下跳的互動點跳下去：綠色「孤注一擲」優先，沒有就走最近的一般互動點。
5. 可下墜次數用完、整場打完（左上出現「離開」）後，照 `settings.json` 的 `hell.chestPriority` 順序開一個寶箱，然後停在原地。沒填就用預設順序：特殊提煉 > 綁定金幣 > 融合 > 天堂 > 破壞石 > 提煉輔助 > 星石 > 碎片 > 命運之石 > 能力石 > 手環。
6. 開完寶箱等 3 秒按「再次挑戰」，選鑰匙（綠色 > 橘色 > 紫色 > 藍色）再入場打下一場，一直打到沒有鑰匙為止。
7. 每一場會記錄到過哪些樓層、開了什麼寶箱（`stats/hell_年-月.jsonl`）。

每隻角色打到沒有鑰匙會按「離開」，再換下一隻。打到一半可以按 F10 暫停、手動操作，再按 F10 繼續；按 Ctrl+F5 停止。地獄、樂園、每日混沌副本不能同時跑。

### 結算表與戰報
每日任務結束時（完成、失敗或手動停止都會），主控台會顯示每個角色的結算表，並在 exe 旁邊的 `reports` 資料夾產生一份 HTML 戰報，用瀏覽器打開就能看（不需要網路）：
- 今日結算：每個角色打的副本與地圖、結果、副本時間、死亡次數、片鱗數、公會簽到 / 捐贈，破這張地圖的本月最快會標示
- 近 30 天每張地圖的通關時間趨勢 (可以點地圖切換要看哪幾張，滑鼠移到線上會顯示那天是哪些角色打的)
- 本月各地圖的場數、平均 / 最快 / 最慢時間、死亡與互動重試次數
- 滑鼠移到地圖名稱上 (今日結算、各地圖統計、通關時間的地圖按鈕)，會跳出那張地圖的小圖與路線
- 死亡位置：在路線地圖上標出每次死亡的地方，以及死亡最集中的位置
- 片鱗：每個角色今天 / 本月出現幾個片鱗 (小地圖上的菱形圖示，加上畫面上「祝福的片鱗 / 命運的片鱗」名牌，同一個片鱗只算一次)，分成命運與祝福；舊紀錄沒有分的都當作命運
- 樂園 (天堂)：今天每個角色打的階段、場數、時間，以及本月每個角色打了幾天 / 幾場。樂園任務 (Ctrl+F8) 結束時也會產生一份戰報 (最上面先顯示這次的樂園結果)
- 各角色本月的副本時間

報表以**角色名字**為單位 (切換角色時從角色列表讀名字)，有多個帳號、同一個角色格是不同角色也會分開統計。舊版的紀錄沒有名字，會用同一個角色格最近讀到的名字。

每場副本的紀錄存在 `stats` 資料夾（一個月一個檔）。想隨時看本月統計，可以執行 `LostArkSmartHunter.exe --report`。

## 自動更新

每次啟動時會檢查有沒有新版，有的話會顯示更新內容並詢問是否更新（按 `Y` 更新）。更新時 `settings.json` 不會被覆蓋。

## 注意事項

- 使用任何自動化工具都可能違反遊戲的服務條款，**請自行評估風險，使用後果由使用者自行承擔**。
- 遇到問題時，exe 旁邊的 `logs` 資料夾有執行紀錄與失敗時的截圖，回報問題時附上會很有幫助。
- 角色名字、混沌副本次數、副本名稱的文字辨識使用 [PaddleOCR](https://github.com/PaddlePaddle/PaddleOCR) 的 PP-OCRv5 模型 (Apache License 2.0)。
